# Предсказание цены на недвижимость

## Описание проекта
Проект направлен на **создание интеллектуальной системы, способной предсказывать стоимость объектов недвижимости** на основе их характеристик (площадь, расположение, этажность, инфраструктура и т.д.).
Основная цель — разработать **модель машинного обучения** и **веб-сервис**, который позволит пользователю вводить данные об объекте и получать прогнозируемую цену.
